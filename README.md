# Apply

## Purpose

This repository is a technical test. It checks your skill with Git,
GitHub, and DevOps workflows. It is public. It is part of a real job
application process.

Read this whole file before you start. It has the steps you must
follow.

## What This Test Checks

The test checks these skills:

- Use of Git branches, commits, and pull requests.
- Correct use of a fork-and-pull-request workflow on GitHub.
- Care with public repositories. Do not commit secret data of any
  kind. Secret data includes passwords, API keys, tokens, and private
  URLs.

## Steps To Apply

1. Fork this repository to your own GitHub account.
2. Create a new branch in your fork.
3. Open the file `automation.md`.
4. Add one row under the header. Put your name in the first column.
   Put a link to your GitHub profile or to one project you built in
   the second column.
5. Commit your change with a clear commit message.
6. Push your branch to your fork.
7. Open a pull request from your branch to the `main` branch of this
   repository.
8. Fill in the pull request description. Use the format in the
   section below.

## Pull Request Requirements

Your pull request description must have these three parts:

1. **Role**: The name of the role you apply for.
2. **Link**: A link to your GitHub profile or to one project you
   built. This must match the link you added to `automation.md`.
3. **Summary**: One or two sentences about the project you linked.
   State what the project does and what you built.

Use this template for your pull request description:

```
Role: <the role you apply for>
Link: <your GitHub profile or project URL>
Summary: <one or two sentences about the project>
```

## Rules

- Do not add secret data to any file or commit.
- Do not change any file other than `automation.md`.
- Write your commit message and pull request description in plain,
  clear English.

## Review

A reviewer will check your pull request. The reviewer looks at your
commit history, your branch name, and your pull request description.
Follow the steps above in order. This shows your process, not only
your final result.
